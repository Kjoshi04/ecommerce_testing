# LiteCart QA Testing Project

This repository contains manual testing deliverables created while testing the LiteCart demo e-commerce website: https://demo.litecart.net/.  
The project demonstrates QA skills including functional testing, UI testing, negative testing, and defect reporting.

---

## Contents
- **Test_Plan.md** – Testing scope, approach, environment, and strategy  
- **Test_Cases.csv** – Detailed test scenarios with expected results  
- **Bug_Report.csv** – Documented defects found during testing  
- **Screenshots/** – Visual evidence of issues (optional)

---

## Website Tested
**LiteCart Demo Store** — https://demo.litecart.net/  
A publicly available demo store used for QA practice.

---

## Tools Used
- Google Chrome  
- Chrome DevTools  
- Windows 10 / macOS  
- Excel / Google Sheets  
- Snipping Tool (Screenshots)

---

## What Was Tested
- Homepage UI and layout  
- Search functionality (positive & negative)  
- Product details pages  
- Add to Cart & Remove from Cart flows  
- Category navigation and breadcrumbs  
- Image gallery / thumbnails  
- Basic negative test scenarios  

---

## Summary of Bugs Found 
- Blank-search behavior needs validation  
- Product image zoom / gallery inconsistencies  
- Cart quantity or total not updating without reload  
- Thumbnail click not updating main image consistently  
- Breadcrumb missing or inconsistent on some pages  

(Full details in **Bug_Report.csv**)

---

## How to Use This Repository
This repo contains **documentation and QA artifacts only**.  
Open the CSV files on GitHub or download to Excel to view details.  
Screenshots are in the `Screenshots/` folder.

---

## Notes
Demo site behavior may vary because public demos sometimes reset content. All bugs were observed during manual testing sessions.
