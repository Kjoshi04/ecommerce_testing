# Test Plan – LiteCart Demo Website (Manual Testing)

## 1. Introduction
This test plan outlines the scope, objectives, approach, and deliverables for testing the LiteCart demo e-commerce website: https://demo.litecart.net/. This project focuses on manual functional, UI, and negative testing of core store features.

## 2. Scope of Testing
### In Scope
- Homepage UI validation
- Search functionality (positive & negative)
- Product details pages
- Add to Cart / Remove from Cart
- Navigation and categories
- Image gallery and thumbnail behavior
- Breadcrumb and navigation checks
- Basic negative input testing (invalid values, empty search, etc.)

### Out of Scope
- Payment gateway processing
- Admin dashboard testing
- Performance/load testing
- Database validation
- API automation

## 3. Testing Types
- Functional Testing  
- UI/UX Testing  
- Smoke Testing  
- Negative Testing  
- Basic Cross-browser check (Chrome)

## 4. Test Environment
- Website: https://demo.litecart.net/
- Browser: Google Chrome (latest)
- Device: Windows 10 Laptop / macOS
- Tools: Chrome DevTools, Excel/Google Sheets, Snipping Tool

## 5. Entry Criteria
- Demo website accessible
- Test cases prepared

## 6. Exit Criteria
- All planned test cases executed
- Identified bugs documented in Bug_Report.csv

## 7. Deliverables
- Test Plan (this document)
- Test Cases (Test_Cases.csv)
- Bug Report (Bug_Report.csv)
- Screenshots (optional)

## 8. Risks & Assumptions
- Public demo may reset often causing intermittent behavior
- Some UI elements may change between sessions

## 9. Conclusion
This plan covers manual verification of key e-commerce flows on the LiteCart demo site to identify functional and UI issues.
